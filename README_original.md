
# TaskMatch

## ระบบประกาศงานและสมัครรับงานออนไลน์

TaskMatch เป็นเว็บแอปพลิเคชันสำหรับเชื่อมต่อระหว่าง
ผู้ว่าจ้าง (Customer) และผู้รับงาน (Worker)
โดยผู้ว่าจ้างสามารถลงประกาศงาน กำหนดรายละเอียด
ค่าจ้าง และวันกำหนดส่งงานได้

ผู้รับงานสามารถค้นหางานที่สนใจ สมัครรับงาน
และติดตามสถานะใบสมัครของตนเองได้

ระบบยังมีผู้ดูแลระบบ (Admin)
สำหรับตรวจสอบภาพรวมและจัดการประกาศงาน

โปรเจกต์นี้พัฒนาด้วยภาษา Go
ร่วมกับฐานข้อมูล MySQL และเทคโนโลยีเว็บพื้นฐาน

---

## 1. วัตถุประสงค์ของโครงงาน

1. พัฒนาระบบประกาศงานและสมัครรับงานผ่านเว็บไซต์

6. พัฒนาเว็บแอปพลิเคชันที่รองรับหลายขนาดหน้าจอ

## 3. ประเภทผู้ใช้งาน

ระบบแบ่งผู้ใช้งานออกเป็น 3 ประเภท

### 3.1 Customer (ผู้ว่าจ้าง)

สามารถดำเนินการได้ดังนี้

- สมัครสมาชิก
- เข้าสู่ระบบ
- ลงประกาศงานใหม่
- ระบุหมวดหมู่งาน
- กำหนดค่าจ้าง
- กำหนดวันส่งงาน
- แก้ไขประกาศงานที่ยังเปิดรับสมัคร
- ดูประกาศงานของตนเอง
- ดูรายชื่อผู้สมัครรับงาน
- ยอมรับหรือปฏิเสธผู้สมัคร
- เปลี่ยนสถานะงานเป็นเสร็จสิ้น
- ลบประกาศงานตามเงื่อนไขของระบบ

### 3.2 Worker (ผู้รับงาน)

สามารถดำเนินการได้ดังนี้

- สมัครสมาชิก
- เข้าสู่ระบบ
- ดูรายการประกาศงาน
- ดูรายละเอียดงาน
- สมัครรับงาน
- ตรวจสอบรายการงานที่เคยสมัคร
- ตรวจสอบสถานะใบสมัคร

### 3.3 Admin (ผู้ดูแลระบบ)

สามารถดำเนินการได้ดังนี้

- เข้าสู่ระบบด้วยบัญชี Admin
- ดูจำนวนสมาชิกทั้งหมด
- ดูจำนวนประกาศงานทั้งหมด
- ดูจำนวนใบสมัครงานทั้งหมด
- ตรวจสอบรายการประกาศงาน
- เปิดดูรายละเอียดประกาศงาน
- ลบประกาศงานที่ไม่เหมาะสม

หมายเหตุ:
ระบบสมัครสมาชิกทั่วไปเปิดให้เลือกเฉพาะ
Customer และ Worker เท่านั้น

สิทธิ์ Admin ต้องกำหนดโดยผู้ดูแลฐานข้อมูล
ไม่สามารถเลือกผ่านหน้าสมัครสมาชิกได้

## 7. ความสัมพันธ์ของตาราง

ความสัมพันธ์หลักของระบบ:

```text
users
  |
  | 1:N
  v
jobs
  |
  | 1:N
  v
applications

categories
  |
  | 1:N
  v
jobs

users
  |
  | 1:N
  v
applications

users
  |
  | 1:N
  v
sessions
```

รายละเอียด:

1. ผู้ว่าจ้างหนึ่งคนสร้างประกาศงานได้หลายงาน
2. หมวดหมู่หนึ่งหมวดหมู่มีประกาศงานได้หลายงาน
3. ประกาศงานหนึ่งงานมีผู้สมัครได้หลายคน
4. ผู้รับงานหนึ่งคนสมัครงานได้หลายงาน
5. ผู้ใช้งานหนึ่งคนมี Session ได้หลายรายการ
6. ผู้รับงานไม่สามารถสมัครงานเดียวกันซ้ำได้

## 8. สถานะของงาน

| Status | ความหมาย |
|--------|----------|

```text
open

  v
assigned
  |
  | ผู้ว่าจ้างยืนยันงานเสร็จ
  v
completed
```

## 11. วิธีติดตั้งโปรเจกต์บน Windows

### ขั้นตอนที่ 1: เปิดโฟลเดอร์โปรเจกต์

เปิด Visual Studio Code

เลือก:

File > Open Folder

จากนั้นเลือก:

```text
D:\TaskMatch
```

### ขั้นตอนที่ 2: เปิด Terminal

ใน Visual Studio Code เลือก:

Terminal > New Terminal

ตรวจสอบว่าตำแหน่งปัจจุบันคือ:

```powershell
D:\TaskMatch
```

หากไม่ใช่ ให้พิมพ์:

```powershell
cd D:\TaskMatch
```

### ขั้นตอนที่ 3: ตรวจสอบ Go Module

พิมพ์:

```powershell
go env GOMOD
```

หากยังไม่มีไฟล์ go.mod
ให้สร้างด้วยคำสั่ง:

```powershell
go mod init taskmatch
```

หากมีไฟล์ go.mod อยู่แล้ว
ไม่ต้องรันคำสั่งนี้ซ้ำ

### ขั้นตอนที่ 4: ติดตั้ง Dependencies

ให้ Go ตรวจสอบ Dependencies
จากโค้ดในโปรเจกต์:

```powershell
go mod tidy
```

คำสั่งนี้จะดาวน์โหลด Dependencies
ที่ main.go เรียกใช้

และอัปเดตไฟล์ go.mod กับ go.sum

## 13. การตั้งค่าการเชื่อมต่อ MySQL

โปรเจกต์ต้องเชื่อมต่อฐานข้อมูลชื่อ:

```text
taskmatch
```

การติดตั้ง XAMPP แบบทั่วไป
มักใช้ค่าดังนี้:

```text
Host:     127.0.0.1
Port:     3306
Username: root
Password: (ว่าง หากยังไม่ได้ตั้งค่า)
Database: taskmatch
```

ค่าข้างต้นเป็นเพียงตัวอย่างสำหรับ
เครื่องพัฒนาในระบบ Local

ให้ตรวจสอบการตั้งค่า DSN
หรือ Environment Variables ใน main.go
และใช้ค่าที่ตรงกับ MySQL ของเครื่องจริง

หาก MySQL ใช้รหัสผ่าน
ต้องกำหนดรหัสผ่านให้ถูกต้องด้วย

ไม่ควรนำบัญชี root ที่ไม่มีรหัสผ่าน
ไปใช้งานบนเซิร์ฟเวอร์สาธารณะ

## 19. วิธีทดสอบ Admin

ระบบไม่อนุญาตให้เลือก Admin
จากหน้าสมัครสมาชิกทั่วไป

สำหรับการทดสอบบนเครื่อง Local
ให้สร้างบัญชีทดสอบผ่านหน้าสมัครสมาชิกก่อน

จากนั้นเปิด phpMyAdmin

เลือกฐานข้อมูล:

```text
taskmatch
```

เลือกแท็บ SQL

ตัวอย่างการเปลี่ยนสิทธิ์บัญชีทดสอบ:

```sql
UPDATE users
SET role = 'admin'
WHERE email = 'admin@example.com'
  AND role = 'customer';
```

หมายเหตุ:
เปลี่ยน admin@example.com
ให้ตรงกับอีเมลบัญชีทดสอบที่สร้างไว้จริง

ควรตรวจสอบว่าคำสั่งมีผลกับบัญชี
ที่ตั้งใจเปลี่ยนสิทธิ์เท่านั้น

จากนั้นออกจากระบบและเข้าสู่ระบบใหม่
ด้วยบัญชีที่เปลี่ยนเป็น Admin

เปิดหน้า:

```text
/admin
```

ตรวจสอบ:

- จำนวนสมาชิก
- จำนวนประกาศงาน
- จำนวนใบสมัคร
- ตารางประกาศงาน
- การเปิดดูรายละเอียดงาน
- การลบประกาศงาน

คำสั่งเปลี่ยนสิทธิ์นี้ใช้เพื่อทดสอบ
ในเครื่อง Local ที่ผู้พัฒนาควบคุมเท่านั้น

## 20. การรักษาความปลอดภัย

แนวทางด้านความปลอดภัยที่ใช้ในโปรเจกต์:

### 20.1 Password Hashing

ไม่ควรจัดเก็บรหัสผ่านเป็น Plain Text

Backend ต้อง Hash รหัสผ่าน
ก่อนบันทึกลงฐานข้อมูล

### 20.2 Session Authentication

ระบบใช้ Session
เพื่อระบุตัวผู้ใช้งานที่เข้าสู่ระบบ

### 20.3 Role-Based Access Control

ระบบกำหนดสิทธิ์ตามประเภทบัญชี

ตัวอย่าง:

- Customer ลงประกาศงานได้
- Worker สมัครรับงานได้
- Admin เข้าหน้าจัดการระบบได้

### 20.4 CSRF Protection

ฟอร์มที่แก้ไขข้อมูลต้องส่ง CSRF Token
และ Backend ต้องตรวจสอบก่อนดำเนินการ

### 20.5 SQL Injection Prevention

ควรใช้ Parameterized Queries
ผ่าน database/sql

ไม่ควรนำค่าที่ผู้ใช้กรอก
มาต่อเป็น SQL String โดยตรง

### 20.6 HTML Escaping

ใช้ html/template
เพื่อช่วย Escape ข้อมูลที่แสดงใน HTML

หมายเหตุ:
การป้องกันความปลอดภัยที่สมบูรณ์
ขึ้นอยู่กับการตรวจสอบและการตั้งค่า
ใน Backend และระบบที่นำไปใช้งานจริง

## 21. การแก้ไขปัญหาเบื้องต้น

### ปัญหา: go ไม่ใช่คำสั่งที่รู้จัก

ตัวอย่างข้อความ:

```text
'go' is not recognized
```

แนวทางแก้ไข:

1. ตรวจสอบว่าติดตั้ง Go แล้ว
2. ปิดและเปิด Terminal ใหม่
3. ตรวจสอบ Environment Variable PATH
4. ลองรัน go version อีกครั้ง

### ปัญหา: เชื่อมต่อ MySQL ไม่สำเร็จ

ตรวจสอบ:

1. MySQL ใน XAMPP ทำงานหรือไม่
2. ชื่อฐานข้อมูลถูกต้องหรือไม่
3. Username ถูกต้องหรือไม่
4. Password ถูกต้องหรือไม่
5. Port ตรงกับการตั้งค่าหรือไม่
6. ตารางถูก Import แล้วหรือไม่

### ปัญหา: เปิดเว็บไซต์ไม่ได้

ตรวจสอบ:

1. go run main.go ยังทำงานอยู่หรือไม่
2. Terminal แสดง Error หรือไม่
3. ใช้ URL และ Port ถูกต้องหรือไม่
4. Port ถูกโปรแกรมอื่นใช้งานอยู่หรือไม่

### ปัญหา: หน้าเว็บไม่มี CSS

ตรวจสอบว่ามีไฟล์:

```text
static/css/style.css
```

และ layout.html เรียกไฟล์:

```html
<link rel="stylesheet" href="/static/css/style.css">
```

จากนั้นลอง Refresh หน้าเว็บ

### ปัญหา: JavaScript ไม่ทำงาน

ตรวจสอบว่ามีไฟล์:

```text
static/js/script.js
```

และ layout.html เรียกไฟล์:

```html
<script src="/static/js/script.js" defer></script>
```

เปิด Developer Tools ของ Browser
แล้วตรวจสอบแท็บ Console

### ปัญหา: หน้า HTML แสดง Template Error

ตรวจสอบ:

1. ชื่อไฟล์ HTML ถูกต้อง
2. ทุกไฟล์มี {{define "content"}}
3. ทุกไฟล์ปิดด้วย {{end}}
4. ตัวแปรใน HTML ตรงกับ Struct ของ Go
5. การใช้ตัวแปรภายใน range ถูกต้อง

ตัวอย่าง:

เมื่ออยู่ภายใน:

```text
{{range .Jobs}}
```

ตัวแปรจุด (.) จะอ้างถึงงานแต่ละรายการ

หากต้องการอ่านข้อมูลจาก View หลัก
ให้ใช้เครื่องหมาย $ เช่น:

```text
{{$.User}}
```

## 23. ขอบเขตของโครงงาน

TaskMatch เป็นโครงงานเว็บแอปพลิเคชัน
เพื่อการศึกษาและฝึกพัฒนาระบบ

ฟังก์ชันหลักประกอบด้วย:

- ระบบสมาชิก
- ระบบเข้าสู่ระบบ
- ระบบกำหนดประเภทผู้ใช้งาน
- ระบบประกาศงาน
- ระบบสมัครรับงาน
- ระบบจัดการผู้สมัคร
- ระบบติดตามสถานะ
- ระบบผู้ดูแลระบบ

ระบบยังไม่ได้ครอบคลุม
การรับชำระเงินจริง
การยืนยันตัวตนทางราชการ
หรือการคุ้มครองธุรกรรมแบบเว็บไซต์เชิงพาณิชย์

ก่อนนำไปใช้งานจริง
ควรทดสอบความปลอดภัย
และปรับปรุงระบบเพิ่มเติม
